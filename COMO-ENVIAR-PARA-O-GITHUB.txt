COMO COLOCAR NO GITHUB

1. Extraia este ZIP.
2. Abra o repositório site-da-karol no GitHub.
3. Envie o conteúdo extraído para a mesma pasta que contém o index.html atual.
4. Substitua os arquivos antigos de mesmo nome e mantenha a pasta assets.
5. Confirme o envio. O GitHub Pages atualizará o site conforme a configuração atual do repositório.

Envie também todos os CSS, JavaScript e a pasta assets. Apenas os HTMLs não bastam.
O index.html deve ficar diretamente na pasta publicada, não dentro de uma nova subpasta.
Preserve os demais arquivos existentes no repositório.

Esta versão inclui NPCs e chefes ilustrados no RPG, diálogos sem números no cenário, quebra-cabeça com montagem salva e guia Como jogar na investigação.

O progresso é salvo por navegador e endereço. O progresso do endereço chatgpt.site não é transferido automaticamente para o endereço do GitHub.
